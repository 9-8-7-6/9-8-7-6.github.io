About

I work at the layer where a program meets the machine: memory layout, kernel launches, toolchain plumbing. Rust on the host side, CUDA on the device side, and a great deal of time spent reading other people's build systems.

The pattern in my work is small and consistent. When a dependency is broken or its documentation is wrong, I patch it upstream. That is slower than a local workaround, and it is the only version that helps the next person who hits the same wall.

I write here about the problems that cost me a day and should have cost an hour. If something is wrong, tell me — I would rather be corrected than quoted.
