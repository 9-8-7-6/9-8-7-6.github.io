This year, I made the transition into AI Infrastructure. During my transition, I spent countless hours reading books, writing code, watching videos, and exploring open-source repositories. These resources helped me tremendously, and I hope they can help others as well.

## English

### GPU

- [NVIDIA CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-c-programming-guide/) — official documentation
- [NVIDIA cuda-samples](https://github.com/NVIDIA/cuda-samples) — GitHub repository
- *Programming Massively Parallel Processors* — book
- [GPU MODE](https://www.youtube.com/@GPUMODE) — YouTube channel
- [cuda-oxide](https://github.com/NVlabs/cuda-oxide) — GitHub repository

### AI / AI Infra

- [Andrej Karpathy's YouTube channel](https://www.youtube.com/@AndrejKarpathy) (highly recommended) — explanations of how LLM training and inference work, along with hands-on tutorials
- [freeCodeCamp](https://www.youtube.com/@freecodecamp) — AI, Machine Learning, and PyTorch courses (YouTube channel)
- [vLLM](https://github.com/vllm-project/vllm) — GitHub repository
- [llama.cpp](https://github.com/ggml-org/llama.cpp) and the Llama source code — GitHub repository
- Research papers from leading AI companies and research labs (OpenAI, Anthropic, Meta, Google DeepMind, DeepSeek, NVIDIA, etc.)
- [Kubernetes](https://kubernetes.io/docs/home/) — repo and official documentation
